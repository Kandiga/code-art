# audio/music - instruments

Orchestra / band / FX palette for the 60 s film (`audio/music/instruments.mjs`). Pure Node ESM, deterministic (seeded per note), 48 kHz stereo float32 `Buf`s
from `audio/lib`. Everything is **dry with its own tasteful character**; reverb is applied by the composer on a bus (recommended preset per instrument below).
Generated by `node audio/music/test/gen_docs.mjs` from the live registry.

## Quick start

```js
import * as inst from './instruments.mjs';
import * as th from '../lib/theory.mjs';          // motifEvents, chordNotes, chordForTime, arp, drumRoll helpers live here / below
import * as dsp from '../lib/dsp.mjs';

const mix = new dsp.Buf(60);
// 1. the motif once per bar on a piano, bars 2-10
const motif = th.motifBars([2, 3, 4], { vel: [0.9, 0.7, 0.75, 0.95] });                      // [{t, dur, midi, vel}] in film time
dsp.addAt(mix, inst.render('piano', motif, { gainDb: -2 }), 0);
// 2. a string pad on the chords with a swell, one reverb send for the bus
const pad = th.chordSpans(26, 42).flatMap((s) => th.chordNotes(s.name, 3, 'open').map((m) => ({ t: s.t0, dur: s.t1 - s.t0, midi: m, vel: 0.7 })));
const strings = inst.render('strings', pad, { art: 'legato' });
dsp.addAt(mix, strings, 0);
dsp.addAt(mix, inst.applySend(strings, 'strings'), 0);                                       // wet-only hall reverb, ADD it
// 3. a riser that lands on the 37.0 s orchestra hit
dsp.addAt(mix, inst.render('riser', [{ t: 35, dur: 2, vel: 0.9 }]), 0);
dsp.addAt(mix, inst.render('impact', [{ t: 37, vel: 1, size: 'L' }]), 0);
```

## Notes (the only input format)

`{ t, dur, midi, vel, pan?, gainDb?, ...instrument-specific }` in **global film seconds**.

| field | meaning |
|---|---|
| `t` | onset (s). Slow-attack voices (strings legato, pads, choir, drone, shimmer, horns) are placed so that their *perceived* onset (about 30 % into the swell) is on `t`; the buffer starts earlier. Percussion / plucks start exactly at `t`. |
| `dur` | gate / key-down time. Each voice adds its own release tail after it (damper fall, bow release, reverb-friendly decay). Plucked/struck instruments ring naturally (`harp` ring 3.2 s, `timpani` until damped...). FX: `dur` = whole effect (riser builds for dur; impact tail; sub_drop length). |
| `midi` | pitch (A4 = 69 = 440 Hz). Drums: kick / snare / toms / timpani / taiko / sub808 are *tuned* by it (defaults sit in the key: kick A1, sub808 A1, timpani A2, taiko D2). Hats / clap / cymbal ignore it. |
| `vel` | 0..1 (default 0.8). Controls level **and brightness** (piano hammer, brass blat, bow pressure, snare wires, filter envelopes). |
| `pan` | -1..1 (default 0) added to the instrument's own stereo image. |
| `gainDb` | per-note trim. |

## render(id, notes, opts)

`opts`: `seconds` (buffer length, default 60 = cues.DURATION), `buf` (mix into an existing Buf instead of allocating), `gainDb`, `pan`, `seed` (default 1: change it to re-roll all the random micro-variation),
`transpose` (semitones), `octave`, `segGap` (s; notes closer than this share one bus pass, default 0.4), `subHz` (subsonic high-pass, default 22 Hz) + the per-instrument options in the tables.
Sparse parts are cheap: only the seconds that actually sound are processed (the rest of the Buf is digital silence).

## Loudness calibration

Every instrument carries a trim (`gainDb`, last column, generated by `test/calibrate.mjs`) so that its reference passage (4 spaced single notes at vel 0.8, or the standard groove for drums) measures
**-26 LUFS** integrated (percussion / FX offsets: kick -22, snare -24, snare_gated -23, hat -32, clap -25, toms -25, timpani -24, taiko -22, sub808 -24, cymbal -29, riser -27, reverse_swell -28, sub_drop -24, braam -20, impact -20, tape_rewind -33, shimmer -28).
That is a *unit balance*: a dozen layers sum to roughly the -17..-14 LUFS of the master. Chords stack (+3..6 dB for 3-4 voices): mix with `gainDb`.

Run processors on the summed stem **after** the reverb send (the room should wobble and hiss with the music) and before the master limiter.

## ERA_STYLES: one arrangement kit per `cues.ERAS[i].music`

## Recipes

```js
// the solo-piano turn (22.5-26.0): grand, pedal down, even quarter notes E G A C, C5 held into 26.0
inst.render('piano_grand', th.motifEvents(24.0, { rhythm: 'even', vel: [0.6, 0.55, 0.7, 0.8] }), { pedal: true });

// timpani roll into the baton-down hit at 37.0, then the hit
inst.render('timpani', inst.drumRoll(35, 37, { midi: 45, rate: 16, vel: [0.25, 0.95] }));
inst.render('cymbal', [{ t: 35, dur: 2, vel: 0.9, swell: true }]);        // peaks at 37.0

// harp glissando up into a downbeat, flute run
inst.render('harp', inst.harpGliss(11.4, 48, 84, { step: 0.04 }));
inst.render('flute', inst.windRun(10.5, 72, 91, { vel: [0.5, 0.85] }));

// era kit: 1960 brass + choir + timpani
const kit = inst.eraKit(cues.ERAS[4]);
const motifBuf = kit.render('motif', th.motifEvents(12, { octave: -1 }));
const padBuf = kit.render('pad', chordNotesAt12);
const out = kit.finish({ motif: motifBuf, pad: padBuf });
```

### Known limits / design notes
* Synthesis only (modal / additive / subtractive / FM / formant); no samples. Strings/choir/brass are convincing *as a mix element behind reverb*, not as exposed solos.
* The choir sings vowels only (ooh/aah/eh/ee/oh and morphs); no consonants.
* `dsp.limiter()` (audio/lib/dyn.mjs) stamps a `gain` array on its result, which shadows `Buf.gain(dB)`; `brickwallBright` returns a clean Buf, composers calling `limiter` directly should rewrap with `Buf.from(r.L, r.R)`.
* Hard cuts (22.0 s) and the 60 s end are the composer's job (`dsp.cutAt`); instruments never write past `opts.seconds`.
